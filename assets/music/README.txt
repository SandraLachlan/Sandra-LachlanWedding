===========================================================
Sandra & Lachlan — Wedding Music Instructions
===========================================================

To play your custom wedding music:
1. Name your audio file: wedding-song.mp3
2. Place it right here in this folder:
   assets/music/wedding-song.mp3

Recommended format:
- Format: MP3 (MPEG Audio Layer 3)
- Bitrate: 128 kbps to 192 kbps (ideal for fast web loading on mobile and GitHub Pages)
- File size: Under 5MB recommended for rapid streaming

The website's music player in `script.js` automatically looks for:
"assets/music/wedding-song.mp3"

If this file is not found, the website displays a graceful tooltip
explaining that the music will play once the MP3 file is placed here.
No external or copyrighted songs are embedded.
